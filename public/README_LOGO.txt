Tempatkan file logo Anda di sini dengan nama "logo.jpg" atau "logo.png" (ukuran persegi direkomendasikan, misal 512x512 piksel).

Sistem secara otomatis akan mencari file dengan prioritas berikut:
1. "/logo.jpg" (Format JPG - direkomendasikan jika logo Anda berupa JPG)
2. "/logo.png" (Format PNG)
3. Fallback teks & ikon geometris "BQA" yang elegan (jika kedua file di atas tidak ditemukan)

File tersebut akan langsung terpasang di halaman Login dan Sidebar utama aplikasi HRIS.
